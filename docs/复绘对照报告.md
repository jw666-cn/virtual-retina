## 3. 复绘方法与校验

- 统一以毫米为模型单位，按图纸比例换算到图纸坐标：减速器 1:2；教学楼 1:200。
- 图框：减速器 A1（841×594，留边 25/10/10/10）；教学楼 A2（594×420，留边 25/10/10/10）。
- 线型分层：OUTLINE / THIN / CENTER / DIM / TEXT / TABLE / HATCH / FRAME。
- DXF：ezdxf R2010；`audit()` 0 errors / 0 fixes。
  - 减速器：814 实体（LINE 349、TEXT 341、CIRCLE 92、SOLID 28、HATCH 4），范围 10,10–831,584。
  - 教学楼：2220 实体（LINE 1968、ARC 18、TEXT 118、CIRCLE 58、SOLID 58），范围 10,10–584,410。
- PNG：减速器 3532×2494（4.2 px/mm）；教学楼 2970×2100（5 px/mm）。
