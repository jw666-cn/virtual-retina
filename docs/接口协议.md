# 对外接口协议（视网膜 → 大脑 / 手）

> 版本：`retina.ws/1`（WebSocket）· MCP 2.x tools
> 原则：本产品**只提供感知**。模型由客户配置，动作由客户选择的“手”执行与审批；
> 这里不定义、也不内置任何具体的手（dsh / openclaw / opencode / 自研均可接入）。

## 1. 数据结构

### 1.1 RetinaFrame（内部 / MCP 图片块）

| 字段 | 类型 | 说明 |
|---|---|---|
| `frame_id` | int64 | 单调递增 |
| `timestamp_ms` | int64 | Unix 毫秒 |
| `source` | `"desktop"` \| `"camera"` | 输入源 |
| `width` / `height` | int | 像素 |
| `dirty_rects` | `[{x,y,w,h}]` | 相对上一帧的变化区域；空数组=整帧 |
| `is_key_frame` | bool | 首帧 / 强制 / 定期关键帧 |
| `pixels` | uint8[H×W×3] | RGB；仅在进程内传递，对外走 JPEG/PNG |

### 1.2 Observation（`observe` 的返回值）

```json
{
  "kind": "frame | unchanged | silence",
  "seq": 12,
  "source": "desktop",
  "is_key_frame": false,
  "changed_ratio": 0.013,
  "dirty_rects": [{"x": 120, "y": 80, "w": 640, "h": 360}],
  "capture_dirty_rects": [{"x": 110, "y": 60, "w": 700, "h": 400}],
  "raw_size": [2240, 1400],
  "reason": "增量帧",
  "fovea": {"enabled": true, "x": 900, "y": 500, "w": 480, "h": 480, "scale": 0.66},
  "silence_seconds": 0.0,
  "image": {"included": true, "mime": "image/jpeg", "bytes": 86553, "cached": false, "data_base64": "..."}
}
```

- `unchanged`：与上一帧无实质变化，`mode=delta` 下立即返回；`image.cached=true` 时图片是上一帧的编码。
- `silence`：静止超过 `bus.silence_timeout_s`，仍会带回最近一帧（`cached=true`），便于手继续决策。
- `frame`：有新画面。

> `image.data_base64` 只在 WebSocket 返回；MCP 以独立的 `image/jpeg` 内容块返回同一张图。
> `image.cached=true` 表示这是上一帧的编码（画面未变化，未重新采集/编码）。

### 1.3 动作 JSON（模型输出 → 手执行）

```json
{
  "action": "click | double_click | right_click | type | key | scroll | drag | wait | observe",
  "target": {"element_id": 5},
  "params": {"text": "demo", "key": "ctrl+a", "dx": 0, "dy": -3, "duration_ms": 300},
  "meta": {"source": "retina", "frame_id": 12}
}
```

`target` 也可以是 `{"x": 640, "y": 420}`（屏幕物理像素，左上原点）。
本服务只解析并返回该 JSON（`action` 字段），**绝不执行**。

## 2. MCP（首选）

传输：

- stdio：`py -3.12 -m vision_retina serve --transport mcp`
- Streamable HTTP：`py -3.12 -m vision_retina serve --transport http --port 8766` → `http://127.0.0.1:8766/mcp`

### 2.1 tools

| tool | 参数 | 返回 |
|---|---|---|
| `retina_observe` | `include_image=true`, `force_keyframe=false` | 文本 JSON（Observation）+ `image/jpeg` 内容块 |
| `retina_ask` | `prompt`, `include_image=true` | JSON：`answer` / `action` / `usage` / `latency_ms` / `frame_id` / `cached_frame` / `observation` |
| `retina_ask_fovea` | `prompt`, `budget_tokens=1200` | 双路：`answer` / `zoom` / `calls` / `prompt_tokens` / `budget_ok` / `crop_safe` / `low` / `focus` |
| `retina_set_region` | `x,y,w,h`（全 null/省略=清除） | `{region, capture}`；越界抛错 |
| `retina_list_sources` | — | `[{name, source, backend, width, height, available, ...}]` |
| `retina_status` | — | 运行状态：capture / bus / brain / hand / safety / counters |
| `retina_health` | `probe=false` | 配置与密钥状态；`probe=true` 会真实调用模型做红/蓝图探测 |

`retina_ask` 的 `action` 仅在模型返回可解析的动作 JSON 时非空。

## 3. WebSocket 兜底（`retina.ws/1`）

连接：`ws://127.0.0.1:8765`（`serve --transport ws --port 8765`）。

握手：服务端先发

```json
{"type": "hello", "protocol": "retina.ws/1", "service": "vision-retina",
 "types": ["observe","ask","ask_fovea","ask_actions","set_region","list_sources","status","health","ping"]}
```

请求 / 响应：

```json
{"id": 1, "type": "observe", "params": {"include_image": true}}
{"id": 1, "ok": true, "type": "observe", "result": { ...Observation... }}
{"id": 2, "ok": false, "type": "ask", "error": {"type": "ValueError", "message": "..."}}
```

| type | params | result |
|---|---|---|
| `observe` | `include_image`, `force_keyframe` | Observation（图片在 `result.image.data_base64`） |
| `ask` | `prompt`, `include_image` | 同 `retina_ask` |
| `ask_fovea` | `prompt`, `budget_tokens` | 同 `retina_ask_fovea` |
| `ask_actions` | `task` | 同 `retina_ask`，提示词预设为“只输出一个动作 JSON” |
| `set_region` | `x,y,w,h` 或全省略 | `{region, capture}` |
| `list_sources` | — | 同 MCP |
| `status` | — | 同 MCP |
| `health` | `probe` | 同 MCP |
| `ping` | — | `{pong: true, protocol}` |

## 4. 错误约定

- 参数错误：`ok=false`，`error.type="ValueError"`，`message` 可直接展示。
- 区域越权：`ValueError`，消息包含白名单范围；不会静默裁剪。
- 模型未配置/鉴权失败：`BrainNotConfigured` / `BrainAuthError`；HTTP 非 2xx 为 `BrainHTTPError(status, body)`。
- 采集不可用：`CaptureUnavailable`（例如 macOS/Linux 当前为接口占位）。

## 5. 兼容性

- 新字段只增不改；客户端应忽略未知字段。
- `protocol` 升级时在 hello 中变更（`retina.ws/2`），旧客户端可继续用 v1 端点。
- 图片格式由 `encode.format` 决定（默认 JPEG，质量 80，最大宽度 1280）。
