# Stage A：视网膜方案 vs 专用 OCR 对比报告

日期：2026-10-20  
范围：A 阶段（识图能力对比）。B（成本/延迟）与 C（通用性/工程化）待确认后执行。  
结论先行：**在干净、字号足够的界面文字上，视网膜方案准确率明显更高（90% vs 65%）且能理解版面；在低分辨率 CAD 图纸上，两者都不可靠，视网膜只多读出房间名/标题，尺寸与公差基本读不出；OCR 的速度与成本优势是数量级的。**

## 1. 方法与环境

| 项 | 视网膜方案 | 专用 OCR |
|---|---|---|
| 采集 | DXGI 桌面复制，截取“刚好显示该图”的无边框窗口区域 | 直接读取同一张源图 |
| 识别 | `deepseek-flash`（视觉+推理），temperature=0，提示词要求逐行转录、不解释 | Tesseract 5.4.0，`chi_sim+eng`，`--psm 6`，灰度+自动对比度，短边放大 2× |
| 计分 | 手工核对的目标词/数值表，归一化后做整词/边界匹配；数字要求前后不是数字或小数点 | 同左 |
| 计时 | 窗口出现 → 抓帧 → 模型返回（含网络与推理） | 预处理 + OCR 进程 |
| 成本 | API token（推理 token 也计费） | 0（本地） |

说明：
- “真实文字图”取本机 DSH 工作台的真实界面截图（1920×1040 裁切），不是合成图；内容为本次 Stage A 的需求文字与侧栏标签。
- 视网膜对两张整页 CAD 首次以 `max_tokens=4096` 调用时，推理 token 耗尽预算、正文为空；改为 16384 后才有输出。这是推理型视觉模型的典型坑，成本按实际 token 计。
- 目标表只覆盖“可人工确认”的文字/数值，不追求全图逐字召回；因此是抽样准确率，不是字符级 CER。

## 3. 关键观察

### 3.1 界面文字：视网膜更准，且读得懂结构
- 视网膜 18/20：侧栏（新会话、插件、自动化任务、工作区、接单…）、消息正文（素材、方法、对比维度、输出、PaddleOCR、Tesseract、token、`reports/ocr_compare.md`）基本齐全；漏掉的是小字号“今日/余额”等。
- Tesseract 13/20：正文识别不错，但侧栏小字与英文混排漏得多；对“新会话/插件”等短标签易丢。
- 这一档是视网膜的优势区：**不需要预先知道文字在哪，能连版面一起读**。

### 3.2 CAD 图纸：两者都不可用，但失败方式不同
- 减速器整页：视网膜只命中 `A1`、`技术要求`；明细表 47 行、47 个序号、尺寸链几乎全未读出。Tesseract 输出基本是线段噪声（0/27）。
- 教学楼整页：视网膜命中 13/27，主要是房间名（教室、教师办公、接待室、门厅、过厅、展示厅、值班室、配电室、花池、入口平台）与图名；轴网数字 1800/5100/4950/7200 全漏。Tesseract 仅 2/27。
- 放大裁切也救不回尺寸：轴网 4 个数字、技术特性 4 个数值，两者都是 0/4。
- 技术特性表出现**数值幻觉**：视网膜把 364 读成 384、把传动比 20 读成 12；这比“读不出”更危险。
- 标题栏：视网膜 3/3（两级圆柱齿轮减速器、1:2、A1），Tesseract 0/3（表格线与文字混在一起）。

### 3.3 速度与成本
- OCR 0.3–2.7 s，本地零 token；视网膜 5–48 s，整页 CAD 单次 8k–14k tokens（推理占 80–97%）。
- 视网膜的延迟主要来自推理；对“只要字”的场景，这是纯浪费。

### 3.4 通用性
- 视网膜能回答“这是什么图、有哪些房间、图名/比例”，OCR 只能给文字流。
- OCR 在干净印刷体/扫描件上更稳、更便宜、可离线；视网膜在低质量、无版式先验的截图上更容易胡编数字。

## 4. 结论：各自适用场景

| 场景 | 推荐 | 理由 |
|---|---|---|
| 界面/截图文字提取（按钮、菜单、消息） | 视网膜（粗读）+ OCR（精读复核） | 视网膜召回高、懂版面；关键数字用 OCR 或人工复核 |
| 印刷体文档/票据/表格扫描 | 专用 OCR（PaddleOCR 优先） | 字符精度、速度、零成本；版面分析可用 PP-Structure |
| 低分辨率 CAD 图纸尺寸/公差 | 都不行，必须矢量源或高分辨率重扫 | 两者均 0–7%；视网膜还会幻觉数值 |
| 图纸“看懂”与问答（房间、图名、视图构成） | 视网膜 | OCR 不产生语义 |
| 大批量、离线、成本敏感 | 专用 OCR | 零 token、快 20 倍以上 |

## 5. 局限

- 目标表是抽样（95 项），不是全字符 CER；不同抽样会改变百分比。
- Tesseract 只用了一个 psm 与一种预处理；PaddleOCR 在 CAD 上可能更好（Stage B 验证）。
- 视网膜结果受模型推理预算影响大；4k 预算会直接空答。
- “真实文字图”是屏幕截图而非拍照；真实拍照的透视/反光会更有利于 OCR 预处理管线，也会更难。
